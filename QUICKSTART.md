# Quick Start - 3 Steps

## 1. Get Icons (1 minute)

Go to: https://favicon.io/emoji-favicons/
- Pick any emoji (🚀 recommended)
- Download
- Rename files to: icon16.png, icon48.png, icon128.png
- Put in this folder

## 2. Load into Chrome (30 seconds)

1. Open: chrome://extensions/
2. Turn on "Developer mode" (top right)
3. Click "Load unpacked"
4. Select this folder
5. Done!

## 3. Try It

- Click the extension icon
- Click "Save Current Page"
- Select some text on a page
- Click "Highlight Text"

## That's It!

No account needed. No credit card. No bullshit.

---

**Too lazy to get icons?**

Edit manifest.json and delete these lines:
```
"default_icon": { ... },
"icons": { ... }
```

It'll work fine without custom icons.
